## What it does

Papio Selector is a Chrome extension for capturing elements on a page and turning them into Page Object Model code, so you spend less time in DevTools hand-writing locators.

## Type a field name, get the locator

You don't have to inspect the element first. Type the name of the field you want, and Papio Selector shows locators for it in several frameworks side by side, ready to paste into your tests.

<Callout>Locators are shown for multiple frameworks at once, so a team migrating between tools can compare them directly.</Callout>

## Getting started

1. Install the extension in Chrome.
2. Open the page under test and open Papio Selector.
3. Capture elements, or type a field name, and copy the generated code.
