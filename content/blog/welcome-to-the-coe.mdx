Test automation knowledge tends to live in private wikis, team chats, and people's heads. This site is an attempt to put it somewhere everyone can use and improve.

## What you'll find here

- **Tools.** Open-source projects for web, mobile, AI-assisted, and security testing, each with a maintainer you can reach.
- **The blog.** Write-ups from practitioners on what worked and what didn't.
- **Community.** A directory of people, filterable by skill and by what they're open to, from mentoring to co-authoring.
- **Collaborate.** A board of projects that need help, each with a lead and an effort estimate.

## How it's built

Every page is generated from files in a public repository. A blog post is a Markdown file. Your profile is a JSON file. When you open a pull request, a preview of the whole site is built so you can see your change before it goes live.

<Callout>If the preview build fails, the log tells you exactly which file and field to fix. You can't break the live site by opening a PR.</Callout>

## Three ways to start

1. [Add your profile](/contribute#add-your-profile) so people can find you.
2. Pick something from the [collaboration board](/collaborate).
3. [Write a post](/contribute#write-a-post) about a problem you solved recently.
